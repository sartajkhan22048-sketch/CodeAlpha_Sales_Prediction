# Sales Prediction using Python

## Project Overview
This project is developed as part of the CodeAlpha Data Science Internship (Task 4).

The main objective of this project is to predict product sales based on advertising expenditure using Machine Learning.

## Dataset
The Advertising dataset contains the following features:
- TV Advertising
- Radio Advertising
- Newspaper Advertising
- Sales

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
- Linear Regression

## Project Workflow
1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Visualization
6. Feature Selection
7. Train-Test Split
8. Model Training
9. Sales Prediction
10. Model Evaluation

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R2 Score

## Project Outcome
The model predicts sales based on the advertising budget spent on TV, Radio, and Newspaper advertisements.
